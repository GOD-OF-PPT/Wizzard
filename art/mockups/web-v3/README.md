## 生成稿审阅

- 01：四入口边界清晰，可用静态场景加语义命中区实现；保留生成图中的书法而非重打标题。
- 02/03：必须实现真实输入和服务端提交，不能仅透明点击图片表单。生成稿里的输入光标和清除图标不是功能。
- 04：示例人数和准备状态不能作为真实房间数据；缺人须显示等待，AI必须真实入座。
- 05：`05-gameplay.png`保留为初稿历史，不作验收基准；`05-gameplay-final.png`更正本地角色和花色，并将选中光环改到必须跟色的青叶5。运行时头像笔触差异仍是未关闭的验收项。
- 08：只设计已接入的体验设置，不沿用无音频资源的虚假音效开关。

交互与验收清单：`docs/18-web-v3-design-and-interaction.md`。
