## 本轮修复及复拍

竖屏计时器原有数字过大、沙漏过高，数字压入底部云饰。按设计近景将数字 6cqw 改为 4cqw，单位 3.4cqw 改为 2.8cqw，数值带移到 42.5%，沙漏改为 40% 大小、6% 顶边。漆木、金环及云饰没有改绘。修复前：`49-timer-portrait-before-20261021.png`；修复后：`50-gameplay-portrait-20261021` 和 `50-play-pending-portrait-20261021` 全景/局部。字号过大问题改善，沙漏笔触和数字字形仍不是源像素复制。

输入巡查又发现：相同的非法牌解释连续触发时，React 字符串值不变，不会重启原有 1900ms 提示计时。旧提示可能在第二次点击后提前消失。`MatchScreen` 现在为每次本地解释增加反馈序号，重复动作重新计时；合法选择仍立即清除旧提示。没有改动规则、合法牌集合、协议或服务端。

反馈修复后重新拍摄 gameplay、gameplay-notimer、play-pending 的两画幅六组，当前捕获记录标记 `afterFeedbackFix: true`。其他页面的正常静态画面不受该提示计时修改影响。原 46 位移修复的六组“待复拍”缺口已补齐；新增保护页两画幅也已有真实 Chrome 对照。
