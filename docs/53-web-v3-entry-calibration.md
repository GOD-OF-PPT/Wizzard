## 实际交互与边界

真实首页 → 创建：3/4/5/6 席依次切换，每次唯一选中且昵称仍为“茶客听雨”；AI 关闭/开启、计时开启/关闭完成往返。清除后焦点回昵称。空提交时只有校验艺术/字体的三个资源请求，未出现新的 WebSocket 创建事件；编辑后 alert 数量 0，无效属性撤销。

真实加入表单把 `a06b0023c4` 过滤/限长为 `060023`，六格保留首位 0。短码 `12` 提交仍停在加入表单并显示原有提示。没有把这种本地校验记为真实失败连接或服务端拒绝验收。

巡查发现 Escape 返回首页后焦点落到文档，未回发起入口。已为 WebHome 的创建/加入入口保存明确的返回目标；修复后分别实测回到 `加入房间`、`创建房间`，创建入口可用 Enter 再开。首页静态艺术和其他入口未改。该键盘路径已验证，独立 focus / hover 设计稿仍是后续缺口。
