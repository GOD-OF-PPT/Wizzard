# “漆环巡游”玩法事实说明

> 用途：微信小游戏人工类目咨询与内部理解度盲测
> 版本：2026-08-23 本地 Cocos 评审切片
> 性质：分类调查制品，不是可上传的最终提交包

## 一句话说明

玩家控制动物旅客在双环漆木路线中持续移动，通过加速、减速和在下一座桥换轨来接取同一种茶灵，并按“目标数量与实际接取数量的差”结算得分。

## 实际可见对象

- 一张连续的内外双环巡游路线；
- 六座连接内外环的木桥；
- 三名同时移动的动物旅客；
- 分布在路线节点上的同一种、同价值绿色茶灵；
- 剩余时间、目标数、已接数和差值；
- 减速、预备/取消换轨、加速三项实时控制。

## 一轮真实流程

1. 观察 5 秒：查看双环、桥位、旅客和茶灵分布。
2. 定标 8 秒：用“少一个 / 多一个”调整本轮接取目标并确认。
3. 巡游 60 秒：旅客持续前进，玩家实时调速，并决定是否在下一座桥切换内外环。
4. 结算：逐名显示目标、实际、偏差和本轮得分。

## 操作与结果

| 输入 | 真实效果 |
| --- | --- |
| 减速 | 将本地旅客速度降低一级 |
| 预备换轨 | 在下一座桥切换内外环；再次点击可取消 |
| 加速 | 将本地旅客速度提高一级 |
| 调整目标 | 改变本轮希望接取的茶灵数量；手动确认和超时均使用当前编辑值 |

- 实际接取数等于目标数：`+20`；
- 未命中目标：`-5 × 绝对偏差`；
- 三名旅客同时行动，不存在轮流选择或等待某人行动的阶段。
