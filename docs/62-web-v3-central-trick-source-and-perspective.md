## 几何与实时数字

`trick-layout-v1.json`记录两画幅的四牌独立四角，运行通过CSS matrix3d映射140×210逻辑框。设计坐标载体按当前舞台宽等比缩放，变换支点为左上角，取消旧统一rotateX/skew。Chrome当前支持所用typed CSS除法，记录实际浏览器版本；更旧浏览器兼容性尚未验收。

四牌逐槽精确复用源矩阵，1–3牌取居中槽、5–6牌在同一范围内插；以位置决定透视，不以花色固定槽。零牌保留原“等待领出”。这些其他张数仅做定向布局核对，没有冒充已有独立设计。

Chrome `DOM.getBoxModel`读取实际投影contentQuad，16组同画幅坐标一致；对源四角最大轴向误差横约0.000075、竖约0.021732设计px。此数证明变换接线，不证明图像/字体通过。实时数字继续Noto Serif SC700，中央独立字号/左上偏置；7和1按原字宽单独处理，1–13仍实时值，不烘焙固定7/3/1/9。
