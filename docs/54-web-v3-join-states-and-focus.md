## 原生行为与失败路径边界

实际观察：短码提示只关联房间码，昵称未被误标无效；空昵称提示关联昵称。输入000007保留首位0和六格显示，Home→ArrowRight→Delete变为00007及末格空白；这不是以DOM直接注入值/状态替代键盘。空白昵称与短码同时存在时，先提示昵称且码未误标。Enter短码校验保持房间码焦点及金环，新WebSocket创建事件为0。Tab/Shift+Tab保持两个输入值、正确显示/隐藏外围图层。
