# 奇术茶馆 Web v3：逐页设计与实现合同

日期：2026-10-16；更新：2026-10-17。当前阶段：横屏逐页实现已接入，Chrome迭代验收中，整体未通过。

## 目标与来源

沿用已选定的微信版奇术茶馆风格：朱漆、午夜蓝、宣纸、旧金、灯笼、原创动物旅者。使用内置 ImageGen 生成每页独立设计稿；不得将一张五状态拼图当作逐页完成，也不得以同风格替代布局一致。

来源：`art/mockups/home-screen.png`、`friend-room-screen.png`、`gameplay-screen.png`、`round-results-screen.png`，以及 `art/asset-manifest.json` 的正式资源。

浏览器产品保持匿名内网使用，React/Vite 为正式载体，规则与协议继续来自既有共享包。没有登录、货币、付费、聊天等新增范围。Chrome 为唯一最终验收浏览器。

## 画布与像素验收

横屏画布 1920×1080，浏览器等比缩放，超宽只留侧边，不裁剪核心界面。每页在实施前测量生成图实际像素尺寸并记录控件矩形，运行时图层和命中区使用同一坐标变换。竖屏采用独立重排，需另存设计与截图，不能用横屏通过代替。

静态画面用相同视口、相同状态、相同内容进行并排与半透明叠加对比。文字抗锯齿和动态分数不作逐像素零差异承诺；主要控件边界、位置、间距和层级必须有实测证据。任何缺页、遮挡、拉伸素材、错误内容、状态不匹配均不得通过。

## 交互合同

- 首页：点击创建/加入先打开对应表单，不立即联网创建，不将加入入口带到空大厅。每次新开表单生成随机茶馆昵称，表单内部编辑与重绘保持稳定。
- 创建：昵称1–12字，3–6席，AI补位与倒计时显式可选；提交期间互斥，收到服务端房间快照后再进入大厅。
- 加入：只接受六位数字，Enter提交，错误就地显示并保留输入；Escape返回首页，焦点回到入口。
- 大厅：只显示真实占座；空位是等待好友。准备/取消与房主AI管理明确区分；至少两名已连接真人满足准备条件才能开始。邀请复制数字房间码。
- 离开：先确认；取消保留会话，确认后等待服务端应答才能清除会话。离线状态给出可理解的提示，不能假装离开成功。
- 牌桌：合法牌高亮，选中牌抬高12设计像素、置顶、归零旋转，邻牌向外让位；确认才发送出牌。切换选择不得重复确认提示动画，计时重绘不得重放入场动画。
- 结算：稳定行高，分数正负区分颜色与符号；按钮始终在面板安全区。练习返回首页，联网返回房间走确认流程。
- 规则：每个章节有真实不同内容，标签对应实际面板；设置提供已接入的合法牌提示和减少动效，独立保存到本机。项目没有正式音频资源，撤去旧版无实际效果的音效开关。禁止仅切换标题而复用同一段正文。
- 焦点：弹窗限制Tab在内部，Escape关闭可关闭弹窗，关闭后返回发起按钮；禁用控件说明原因。
- 动效：按钮反馈120–180ms，入场220–240ms，选牌140ms cubic-out，确认提示单次560ms；reduced-motion禁用非必要动画。

每一行均完成生成稿入库、交互规格、实现、Chrome真实操作、同状态截图、设计对照、修复后复拍。`design-qa.md`记录当前真实结论；在任一页面存在P0/P1/P2差异或未验证时保持blocked，不沿用以前的passed标签。

## 本轮实现与验收证据

- 新组件：WebHome、RoomEntry、WebLobby、WebMatchChoices、WebResults、WebRules、LeaveDialog；全屏场景与静态装饰来自ImageGen独立底板，玩家、昵称、码值、分数与状态为DOM动态内容。
- `art/runtime/web-v3/`保留无动态信息底板与透明控件素材；`art/mockups/web-v3/`为不可被实现截图覆盖的视觉目标。
- Chrome localhost与127.0.0.1两个独立匿名会话真实创建/加入同房间，完成双方准备、四名AI增补和开始条件检查；不是以空大厅截图代替联网验收。
- Chrome完整首轮操作：选朱结→预测0→选择唯一合法手牌→确认出牌→第1轮结算。证据：`art/review/web-v3/11-chooser-live.jpg`、`10-bid-live.jpg`、`05-selected-live.jpg`、`06-results-live.jpg`。
- 选牌computed style实测：translateY=-12，zIndex=30，transition=0.14s；确认按钮启用并播放0.56s单次动画。此证据只覆盖首轮单张牌，不能代替多手牌切换/倒计时重绘验证。
- `?design-review=results|ranking|rules`仅在Vite开发模式加载冻结排版样例，不连接房间服务，不承担规则逻辑。构建产物已检查不包含此入口或样例标记。样例截图仅证明指定内容排版，不证明完整游戏流程。
- `06-results-comparison.png`为同内容源稿与Chrome无损截图并排对照，仍可见字体/头像差异，未通过像素级验收。
