# 奇术茶馆

好茶 · 好友 · 好对局

## 游戏简介

《奇术茶馆》是一款以国风奇幻茶馆为舞台的预测型策略卡牌游戏。灯笼初上，山城入夜，六方旅人围坐朱漆圆桌，在一盏清茶间展开观察与判断的较量。玩家需要先预测本轮能够赢得的墩数，再通过跟色、王牌与特殊牌的运用，精确实现自己的判断。支持3—6席好友房、AI补位与单人练习，在轻松友好的氛围中，体验读懂牌局、把握时机、预测命中的乐趣。

## 主题诠释

“茶馆”承载相聚与交流，“奇术”体现牌局中的巧思与变化。青竹客、云游鹤、花间狐等原创旅人因茶结缘，以牌会友。朱漆木桌、宣纸卡面、暖金灯笼与夜蓝山城共同营造温暖、灵巧而略带神秘的东方幻想空间。每一局既是一场判断力的切磋，也是一段与好友共享的闲适时光。

## 核心玩法

1. **围桌入局**：创建或加入3—6席好友房，可由AI补齐空位，也可进入单人练习。
2. **观察与预测**：每轮发牌并确定本轮王牌后，根据手牌、王牌与公开信息，预测自己将赢得0至本轮手牌数中的几墩。每位玩家各出一张牌形成一墩，由牌力胜者收取。
3. **跟色与控墩**：轮流出牌，持有领出花色的普通牌时需要跟色；结合王牌和特殊牌，把握赢墩或让墩的时机，尽量使实际赢墩数与预测一致。
4. **精准计分**：预测命中获得20分基础分，并按每墩追加10分；预测偏差则每差一墩扣10分。例如预测2墩、实际赢2墩可得40分，实际赢1墩或3墩均扣10分。
5. **八轮定胜负**：快速局进行8轮，每轮手牌从1张递增至8张，信息与策略空间逐步增加，最终累计总分最高者获胜。

## 简短介绍

灯下品茶，围桌斗智。《奇术茶馆》将国风茶馆与预测型卡牌策略融合：先判断能赢几墩，再通过出牌精确兑现预测。与好友围桌切磋，或和AI轻松练习，在八轮渐进的牌局中体验观察、取舍与巧思。
