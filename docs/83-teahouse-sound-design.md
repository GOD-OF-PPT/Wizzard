# 奇术茶馆音效设计 v1

2026-10-28。面向当前 React/Vite 好友房与单人练习，延续奇术茶馆的漆木、纸牌、茶具、竹与玉铃质感。目标是让动作清楚、重复舒适、奖励有层次。16 类选定音效已接入网页，独立试听页保留全部候选；Cocos/微信载体尚未接入。

## 声音语言

高频操作用短、干、柔的木与纸；确认采用低声瓷盖；回合提示和奖励才加入少量玉铃。避免刺耳金属声、电子蜂鸣、夸张低频、人声和长混响。不开循环环境声，不用背景音乐掩盖动作。音效层级从轻到重：选牌/按钮 → 落牌/确认 → 本人行动提示 → 正中预测 → 总榜胜出。

## 播放合同

- 只在首次明确用户操作后解锁 Web Audio；页面加载、静默恢复、切回标签页不能突然播放。
- 选牌与按钮声音可即时反馈。出牌、预测提交、机器人加入、准备与开局声音必须等待对应 ACK 或权威快照；pending、重绘与重连重放不触发。
- 发牌以 `matchId + round` 去重；行动提示以 `matchId + round + phase + currentPlayerId` 去重；出牌以命令/事件 ID 或快照版本去重；结算以轮次/比赛 ID 去重。
- AI 连续出牌的普通落牌音压低 4–6dB；不为每个 AI 行动播“轮到你了”。倒计时每秒不发声，无倒计时房不生成虚构警报。
- 进入轮结算时，普通卷轴声与“预测正中”二选一；最终总榜的胜出/完成二选一，避免同一帧叠三种奖励声。
- 最多同时 4 个声部；高优先级本人提示/结算可抢占最旧的低优先级 UI/纸牌声。文件清单提供各类冷却时间。
- 离开页面/隐藏标签时停止当前声音，不在恢复时补播。音效开关与音量仅保存本机；不可把客户端偏好传进纯规则引擎。
- 音效设置需先有与选定页面稿一致的设计再加入现有设置页。本次独立试听页只用于挑选声音，不改游戏页面布局。

## 生成与保存

使用 ElevenLabs 官方 Sound Effects 工作台、SFX v2。每类一次生成四个候选；不开循环，提示词影响保持工作台显示的 30%。提示词保存在 `art/prompts/audio/teahouse-v1/`；原始下载及逐组来源记录在 `art/source/audio/teahouse-v1/`；轻量候选输出在 `art/runtime/audio/teahouse-v1/`；机器可读清单为 `art/audio-manifest.json`。

16 类共 64 个候选已下载并通过逐组 SHA-256 唯一性检查。网页积分从 9,524 变为 8,796，本批观察到消耗 728 积分。初始技术默认 MP3 合计约 209 KB；随后按用户委托完成以下候选选择。全部输出可解码、单声道 44.1kHz/128kbps，无输出裁切采样；64 个原始候选与处理候选均保留。技术测量及连续试听时间轴在 `art/review/audio/teahouse-sfx-v1-metrics.json`。

## 网页接入与实际验证

- `src/web/audio/assets.ts` 只导入16个选定文件；原始候选、试听串和 ZIP 不进入正式网页 bundle。
- `GameAudioPlayer` 负责可信手势解锁、预载/解码缓存、失败静默、500ms过期丢弃、冷却、最多4声部及优先级抢占。音效总线增益为0.65，AI普通落牌额外乘0.5；隐藏、离页和静音取消当前声源及待播放定时器，不补播。
- `MatchAudioTracker` 只观察权威快照/事件，不执行游戏规则。按比赛、轮次、墩、玩家与牌ID去重；旧版本丢弃，相同版本重绘无声，预测/王牌/落牌不在发送命令时冒充完成。
- 好友房在 `useFriendRoom` 同步订阅权威更新，避免 React 帧与倒计时重绘造成重复；每次恢复的首份状态静默建立基线。单人练习共用同一观察器。真人加入、AI增减、本人准备和离房确认有对应音效。
- `体验设置` 的第三个原有纸框为 `游戏音效`，`恢复默认` 使用原有页脚牌匾；横屏和390×844竖屏截图已保存。开关默认开启，跟随本机偏好保存；`M` 可在牌局中切换，输入框内不抢按键。
- 11 项定向检查覆盖命令/事件重放、旧版本、隐式快照确认落牌、恢复静默、结算互斥、并列第一、本人与AI音量、回合/王牌/赢墩、新局开场、静音/手势、异步解码取消和4声部上限。网页 TypeScript 与生产构建通过。
- Chrome 原生 WebAudio 事件证明首次点击后 Context 从 suspended 进入 running，并创建 AudioBufferSource。真实好友房添加机器人、本人选牌和确认落牌分别观察到一个声源；关闭音效后的点击和M静音后的加预测均为0声源；刷新恢复同一无倒计时网络牌局为0声源。
- 证据在 `art/review/audio/integration-20261028/`。总榜奖励/其他结果分支由定向状态检查覆盖，本轮未用浏览器打完八轮；真机扬声器、Cocos/微信播放和人工听感仍未验收。当前仅本地接入，未提交推送或发布 Railway。

连接器的音效相关工具本次返回不可用，因此改用已登录的官方网页。最初两条过长提示词没有生成记录，积分保持不变；压缩为 450 字符以内后生成成功。后续仅对确认已有结果的候选执行下载，不重复生成重试。下载菜单标注 MP3 44.1kHz，但已实测部分原始 MP3 为 48kHz；以 ffprobe 实测为准，保留原始文件。工作台的自动优化状态保持开启，清单保存提交提示词；不声称服务器未返回的内部改写文本。

## 验证边界

技术复核包含文件可解码、实际时长、通道、解码采样峰值、RMS 电平、前导静音和 SHA-256；技术选型不能代替听感。表格的 LUFS 为后续混音目标，尚未通过完整真峰值/LUFS 混音验收。一个按钮候选接近静音，完整保留但排除默认选择。网页运行接线与Chrome声源证据见上一节；移动设备扬声器、Cocos/微信与人工逐条听感验收仍未完成。
