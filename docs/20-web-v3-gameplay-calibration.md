## 动态实现

- 玩家昵称牌覆盖头像下缘，预测/赢墩共用紧凑状态条；本地另有“你”标记。数据来自 game-core/服务端。
- 选牌仍保留12px上提、零旋转、z=30、邻牌左右9px避让；140ms上提及首次选择560ms确认脉冲。倒计时重绘和同回合换牌不重新脉冲。
- MatchScreen 只有本地 PracticeSurface 才创建 useLocalMatch；传入网络控制器不再暗中启动另一局本地规则/计时器。
- 结算继续/再开受服务端 canContinueRound/canRematch 限制；非房主不能通过按钮发起再开。
- CSS 由 main 按旧样式→v3顺序加载，避免旧同优先级规则覆盖黑色牌面数字。Windows Vite 使用轮询观察，修正文件已换而浏览器仍被服务旧模块的问题。
- 退出确认在设置 inert 之前保存触发焦点；取消/Escape 后回到原按钮。确认只在 room.leave ACK 后清会话并回首页。
