## 源图与运行资产

`art/source/web-v3/hud-source-v1/catalog-v1.json` 保存26份组件参考的原图路径、矩形与 SHA。`tools/extract-web-source-actions-v1.mjs` 只提取原绿漆/金框/云饰的连通轮廓并填充内孔，所有不透明 RGB 不改。`src/web/source-action-assets.generated.ts` 登记14张当前动作裁片，`src/web/source-actions.ts` 将每种画幅的源矩形换成舞台坐标；视觉高度保持原比例，触摸范围至少44 CSS px，密集竖屏向上扩展触摸区而不移动图像。

两个资产代理依 Product Design image-to-code 的资产步骤调用内置 ImageGen。空白纸牌候选均有上下白边、纸色和框漂移，整张未采用。`tools/compose-web-source-trump-v1.mjs` 只将配准/色调匹配后的内部纹理用于日轮和可变名称区；固定前缀及框外 RGB 受保护。横屏状态牌保留较大原桌面静区并羽化8px，覆盖背景里不一致的旧空家具，细微桌纹/采样差异仍列 P2。

纠字 v1 候选分别出现近似“猪”或仍为“藏”的字形，被拒用；v2在放大后核对为左“赤”右“者”。提示、原始候选和局部字形检查图均保留。`tools/correct-web-sun-copy-v1.mjs` 只将 v2 字形 alpha 拟合到原单字墨迹范围，并用已有 ImageGen 纸纹清除旧字；原“日”、前缀及 ROI 外像素不改。18张可见状态源另存 `*-copy-v1.png`，由 `copy-correction-provenance-v1.json` 明确映射当前28组来源；被弹层遮挡的10组不补造隐藏像素。状态清单仍为34保存状态×双画幅，这18份是局部修订，不是新增设计状态。

四张 chooser 运行叠图也局部纠字并保留完整 alpha；不透明整页不会代替原透明叠图。当前共有26张活动运行 PNG（14动作＋2纸牌＋2日轮＋2名字＋2状态＋4chooser），另两张旧竖屏预测v1只作历史、不导入。Vite按实际内容发出21个独立PNG文件和4份内联PNG，并去重一对内容相同的横屏未选动作；26个源文件均有对应字节哈希，不以输出文件名前缀误判资源缺失。

## 真实随机练习与边界
