# Web v3 连接反馈与大厅校准

日期：2026-10-18。整体目标仍active，视觉总验收仍blocked。

## 连接反馈设计与交互

ImageGen设计先保存为`art/mockups/web-v3/[portrait/]12-connection-error.png`、`13-connecting.png`，再由`ConnectionDialog`接入。运行时副本为`art/runtime/web-v3/[portrait/]connection-error-v1.png`、`connecting-v1.png`；静态文案与背景不可变，按钮是可访问的真实DOM命中区，没有以图片代替请求行为。

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 正在连接 | 返回修改或Escape | dispose当前客户端，取消等待，回到原表单，保留昵称、码、座位和选项 |
| 正在连接 | Tab | 只有一个操作，焦点留在返回修改；底层表单inert |
| 请求成功 | 服务端快照到达 | 才进入真实大厅，不在点击提交时提前进入 |
| 请求失败或既有8秒超时 | 显示失败稿 | 表单不卸载，失败原因用稳定、可理解的提示，不暴露技术堆栈 |
| 失败 | 返回修改或Escape | 隐藏反馈并聚焦房间码（创建时聚焦昵称），不返回首页 |
| 失败 | 重新连接 | 重新校验并使用当前保留的输入发起新连接 |

模态淡入220ms。静态对照的等待态通过界面的“减少动效”选项采集，opacity实测1；完成后通过恢复默认撤销该临时偏好。动效与无动效证据分开，不把过渡帧计入静态验收。

Chrome真实流程：

- 127.0.0.1独立匿名会话提交不存在的000000，出现失败；重试仍失败；Escape返回后昵称`连接验收茶客`和码`000000`保留，焦点为六位房间码。修改为当时真实房间354453后成功进入。
- 等待态采用临时本地TCP握手延迟器，而非注入React状态。浏览器确实等待WebSocket升级；返回修改终止请求。8秒路径最终出现失败页。延迟器已关闭，正式`npm run room:dev`已恢复8787。
- 服务恢复后，被取消的表单仍停留在原输入页，没有迟到跳转。静态连接中截图不能证明联机加入成功；两类证据分别保存。
- 当前对照：`art/review/web-v3/{12-connection-error,13-connecting}-{portrait,landscape}-live-20261018.jpg`，相同前缀的comparison/focus/overlay/metrics。JPEG与Windows重采样不用于宣称AE=0。

## 大厅校准与局限

- 昵称牌不再借用规则导航板；生成稿中的云瓣端头由独立ImageGen位图复现。状态胶囊v1过扁未采用，v2主体620×201，比例3.085:1。近不透明内区alpha251–254仍保留，不手工补画。准备勾也是独立位图。
- 姓名牌按源稿叠在头像底缘，而非继续垂直追加整行。修复前横屏右下席位底809.63、开始按钮顶790.56，存在重叠；修复后席位底772.51，间隔18.05px。此测量为1672×942 Chrome视口中的16:9舞台，比较时归一化1672×941。
- 3/4/5/6席位置索引分别为`[1,3,5]`、`[0,2,3,5]`、`[0,1,2,3,5]`、`[0,1,2,3,4,5]`。真人从前往后占位，AI从末端占位，未占座不渲染虚构玩家。
- 实际三席房332477：两个匿名真人、一个AI，双方准备后开始按钮启用；双方通过确认离开收到应答后返回首页。证据`04-lobby-3seat-portrait-network-20261018.jpg`。
- 实际四席449784、五席667969、六席427364分别完成创建、人数正确、座位/邀请/管理/动作区碰撞检查与确认退出；检查交集列表均为空。证据`04-lobby-{4seat-landscape,5seat-portrait,6seat-landscape}-network-20261018.jpg`。这些截图只有一个真人，不冒充全人数准备或满座比赛。
- `?design-review=lobby`为仅开发冻结排版样例，不连接服务且按钮不发送命令；和结果页样例相同。用于同昵称/码/准备状态对照，不用于证明业务流程。生产构建必须移除该入口与样例。
- 同内容对照为`04-lobby-fixture-{portrait,landscape}-refined-20261018-{comparison,focus}.png`。源稿自身的计数/按钮语义错误、头像形象差异、邀请和管理区图标缺失仍明确未通过；不为贴图而放宽服务器开始条件。
- 大厅`masked-traveler`已接入独立ImageGen棕色动物兜帽头像，不再误用总榜的人类肖像。原总榜资源不覆盖；其余头像笔触/姿态与跨页身份统一仍需继续对照。复拍已包含新动物头像及抬高的准备勾，旧联机截图不冒充这些美术修改后的最终像素证据。
