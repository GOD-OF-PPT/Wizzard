# Web v3 对局恢复交互合同

## 设计目标

参考同一奇术茶馆牌桌和午夜蓝金框反馈语言，15号为自动恢复中，16号v2为当前连接已结束。两种画幅分别设计，稿及提示保存在 `art/mockups/web-v3/`、`portrait/` 和 `art/prompts/`。16号v1“座位失效”不能泛指所有终止错误，保留历史但不消费。

## 状态与行为

| 真实状态 | 页面反馈 | 可执行动作 |
| --- | --- | --- |
| 已绑定房间，连接丢失/恢复中 | 15号阻塞模态；保留最后的房间和牌局，不伪造秒数、进度或恢复成功 | 立即重试：重用原匿名会话，提前发起一次重连 |
| 已存会话启动恢复 | 同15号；尚无快照时不伪造玩家/分数 | 同上 |
| session.established并取得合法快照 | 撤去15号，继续当前服务端状态 | 正常操作；待确认命令仍由原ID负责 |
| 终止的会话/协议错误 | 16号v2；停止假重试，不重新开房/加入 | 返回首页：显式丢弃失败的本地恢复会话 |

普通对局/大厅业务拒绝不是连接终止，不显示16号。首次创建/加入的等待和失败继续使用12/13号表单反馈，输入保持挂载。关闭浏览器或取消离开确认不清已绑定会话。

## 必须保留的边界

- 网络与本地练习是独立路由状态。没有网络快照时不得自动启动新单人局。
- 恢复中底层 surface inert，不接受出牌、预测、开始、准备或离开。模态内Tab约束，Escape不放弃会话；不在断线时假发送room.leave。
- 立即重试不得清 pendingCommands、resumeToken、最新快照或原房间；旧socket代际失效后才换新连接。未确认命令不因TRANSPORT_ERROR被当作失败释放。
- 只有服务端session.established与合法快照可撤去恢复反馈；不能把WebSocket open当恢复完成。
- 终止后显式返回首页可清失效会话；普通联网离开仍须ACK。协议不兼容的文案不能谎称玩家座位必然丢失。

## 验收计划

Chrome同视口验证15/16横竖状态、焦点约束、立即重试、原房间/原身份/快照恢复和真实终止清理。冻结视觉样例只证明模态排版，网络恢复需真实transport中断/恢复证据。未完成项在design-qa.md保留blocked。

## 2026-10-18 当前实际证据

- `15-reconnecting-{landscape,portrait}-20261018.jpg`、`16-session-ended-{landscape,portrait}-20261018.jpg`为同内容冻结排版样例，分别已有全景和聚焦 source/Chrome 比较。PC1672×941、竖屏390×694；抽取后的模态仍有少量笔触、边饰、光学位置差异，不能宣称逐像素相同。
- 新建独立真实房间服务8791和仅本机回环代理5174。`tools/review-web-recovery-proxy.mjs`只转发真实HTTP/WS，断线按钮关闭transport，不注入DOM/游戏数据/服务端消息。正常项目服务8787未重启。
- 真实房874422，两匿名真人青竹客/花间客准备后补一AI开始。关闭两条真实WebSocket后，15号模态出现，原手牌仍在DOM，screen-layer为inert，焦点在立即重试；断网期间点击重试仍是恢复态，没有假成功。
- 恢复转发后自动恢复到同一玩家/第1轮/朱结10，模式仍为好友对局，没有新单人局。服务端可在断线期间按30秒重连宽限推进其他玩家，恢复后显示其最新权威预测，不冻结或回滚服务器时间。
- `15-reconnecting-{landscape,portrait}-network-20261018.jpg`和`15-recovered-landscape-network-20261018.jpg`为上述真实流程截图；内容不是第4轮设计样例，不与冻结排版证据互换。
- 只重启专用8791内存QA服务后，两个旧会话真实恢复失败，出现16号终止界面。双方点击返回首页并重新加载，均仍停首页、无恢复弹窗，证明未重新绑定失效会话。相应证据`16-session-ended-{landscape,portrait}-network-20261018.jpg`。
- 冻结样例中Tab留在立即重试，Escape不关闭恢复态；原底层控件inert。非房主总榜的“等待房主再开”实测disabled，仅证明权限投影，不冒充8轮真实终局流程。

仍需后续核验：pending命令恰好处于发送/ACK边界时的恢复、更多阶段的焦点与服务端推进、各画幅模态像素校准及边缘残色清理。已有App和本地练习用例通过；Cocos网络用例并不覆盖Web新增RoomSocketClient方法，不能作为该方法的独立证明。
